# Naskah Demo 5–7 Menit

**Menit 0:00–0:45 — Pengenalan**
Jelaskan SIPER, masalah pencatatan manual, teknologi PHP Native/MySQL/Laragon, dan tiga role.

**Menit 0:45–1:30 — Role dan otorisasi**
Login admin, tunjukkan katalog. Login petugas dan tunjukkan menu transaksi. Login anggota dan tunjukkan riwayat pribadi. Coba URL terlarang untuk memperlihatkan penolakan backend.

**Menit 1:30–2:45 — Integrasi**
Sebagai petugas, buat transaksi peminjaman. Tunjukkan data anggota dan buku dipilih dari tabel master, transaksi tersimpan, serta stok berkurang.

**Menit 2:45–3:30 — Pengembalian**
Proses pengembalian. Tunjukkan status berubah dan stok bertambah. Buka laporan untuk memperlihatkan data JOIN.

**Menit 3:30–4:45 — Validasi**
Coba nama anggota kosong, email salah, jumlah pinjam 0/6, tanggal jatuh tempo tidak valid, dan stok tidak cukup. Jelaskan frontend membantu input, backend tetap menjadi pemeriksaan utama.

**Menit 4:45–5:45 — Debugging**
Tunjukkan bug latihan yang direproduksi, bukti dari database/log, akar masalah, perubahan kode, lalu hasil tes ulang. Jangan menyebut bug sebagai temuan jika belum benar-benar direproduksi.

**Menit 5:45–6:45 — Testing dan regresi**
Buka matriks test case, jelaskan kasus positif, negatif, batas nilai, role, integrasi, dan regression test. Tunjukkan bukti screenshot dan hasil aktual.

**Penutup**
Simpulkan bahwa fitur selesai jika alur normal, input tidak valid, akses role, konsistensi relasi, dan tes regresi telah diperiksa.
